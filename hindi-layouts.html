Remington Gail, Inscript and Kruti Dev: which Hindi layout should you learn?

Three names come up again and again in Hindi typing. Here is how they differ.

Inscript

Inscript is the standard Indian-language keyboard layout. It is built into Windows and most phones, and it places vowels and consonants in a logical pattern shared across Indian scripts. Many central recruitment tests specify Inscript.

Remington Gail

Remington is a layout that follows the old Hindi typewriter. Some exams specify it together with the Mangal font, which is a Unicode font. Because it copies the typewriter, some vowel signs are built from two keys and some half letters are typed with Shift, for example Shift plus a consonant key gives the half form. People who learned on typewriters often prefer it.

Kruti Dev

Kruti Dev is an older font-based system. Its key positions are close to the typewriter style, but the text is not stored as standard Unicode, so it usually has to be converted before it can be used on the web or in modern apps. Some older exam formats still use it.

Quick comparison

LayoutStyleText type
InscriptLogical, standardisedUnicode
Remington GailTypewriter styleUnicode with Mangal
Kruti DevTypewriter style, font basedLegacy font

Which should you learn?

Learn the layout your exam notification names, and stick to one. Switching between layouts slows you down because your fingers keep returning to the old positions. If your notification says Remington Gail with Mangal font, practise only that. Read the notice carefully, because the layout, font and time limit are all listed there.
